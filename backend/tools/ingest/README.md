# ingest — تحويل ملفات التشريعات (PDF) إلى مكتبة منظمة

خط معالجة يحوّل ملفات القوانين إلى مواد مرقمة (content/laws) تُرفع لقاعدة البيانات بـ `npm run setup`. ملفات PDF المرفوعة من اللوحة تُعالج على جهازك بـ `npm run process-queue` (يستدعي `process_pdf.py`).

## المراحل
1. **استخراج النص** حسب نوع الملف (`method` في `registry.py`):
   - `text`: ملف PDF به طبقة نص سليمة → `pdftotext` + إصلاح اتجاه النص (bidi) والأقواس المعكوسة والحروف بأشكالها المطبعية.
   - `manual`: تفريغ يدوي في `manual/<id>.txt` (فواصل الصفحات `=== صفحة N`) — يُستخدم تلقائيًا إن وُجد.
   - `ocr`: صفحات مصوّرة أو خطوط مشفّرة → `ocr_queue.sh` (Tesseract + نموذج `ara` من tessdata_best). **ناتجه مسودة غير منشورة.**
2. **تطبيع عربي** (`norm.py`): إزالة علامات الاتجاه والحروف الخاصة، NFKC، توحيد الأرقام الفارسية، ضم الحروف المنفصلة.
3. **إصلاحات خاصة**: خط القانون المدني الذي يحوّل (ك) إلى (آ) يُصلح بقاموس مبني من باقي القوانين؛ كلمات OCR تُصحح بمقارنة القاموس.
4. **تقسيم المواد**: مواد الإصدار `(المادة الأولى)`، مواد القانون `مادة N` / `المادة N` / `مادة N مكررًا`، حواشي التعديل `(معدلة بالقانون ...)`،
   العناوين (الكتاب/الباب/الفصل/الفرع) تُلحق بكل مادة، والتوقيع والختام يُفصلان عن نص آخر مادة.
5. **المخرجات** في `content/laws/`: ملف لكل تشريع `{meta, preamble, interlude, closing, articles[]}` + `index.json` + `REVIEW.md`.

## التشغيل
```bash
sudo apt install poppler-utils tesseract-ocr qpdf          # مرة واحدة
curl -L -o /usr/share/tesseract-ocr/5/tessdata/ara.traineddata \
  https://raw.githubusercontent.com/tesseract-ocr/tessdata_best/main/ara.traineddata
mkdir -p src && cp /path/to/pdfs/*.pdf src/                 # بنفس أسماء الملفات المذكورة في registry.py
python3 repair_pdf.py src/law_no__14_of__2025.pdf           # ملفات بها صفحة HTML ملحقة → *.fixed.pdf
./ocr_queue.sh law-72-2017:src/law-72-2017.pdf:220          # للملفات المصوّرة فقط (قابل للاستئناف)
python3 ingest.py                                           # كل التشريعات، أو: python3 ingest.py law-14-2025
python3 books.py                                            # الكتب والأبحاث → content/books/
# ثم من مجلد backend:  npm run setup   ← يرفع content/laws لقاعدة البيانات
```

## إضافة تشريع جديد
أضف سطرًا في `DOCS` داخل `registry.py` (المعرّف `law-<رقم>-<سنة>`، العنوان، التصنيف، الطريقة). لا تضع `status` إلا إذا كانت الحالة مؤكدة؛
استخدم `suggested` + `suggested_note` لتظهر في `REVIEW.md` لمراجعة الأدمن.

## قاعدة الجودة
- `TEXT_LAYER` و`TRANSCRIBED` → `verified: true` ومنشور.
- `OCR` → `published: false` (مسودة): لا يظهر في التطبيق ولا يستشهد به الـ AI حتى يُراجع أو تُرفع نسخة نصية.

## إصلاحات الخطوط المدعومة
`fix_kaf` (ك←آ)، `fix_lig` (حروف الربط المعكوسة: ال/لا، إل/لإ، جل/لج…)، `mirror` (أقواس معكوسة)، `watermark`
(حذف "صورة إلكترونية لا يعتد بها")، `amending` (قانون معدِّل: لا تُقسّم المواد المقتبسة داخله). كلها أعلام في `registry.py`.

## مصادر بخطوط مشفّرة (بدون OCR)
- `decode_t3` (`decode_ahram.py`): خطوط Type3 للجريدة الرسمية التي يظهر نصها كرموز Mac ("≤∞±∑"). جدول رموز الحروف حُدد من رسم الخط نفسه ثم عُيّر بقاموس المكتبة.
- `decode_tte` (`decode_tte.py`): خطوط Windows العربية المضمّنة بلا Unicode — أرقام الحروف (glyph ids) تتبع ترتيب Presentation Forms-B.
- `visual`: Unicode صحيح لكن مخزّن بترتيب بصري.
النتيجة `DECODED` = نص الناشر الأصلي بأرقامه الصحيحة (موثوق، بخلاف OCR).

## النصوص المجمّعة المحدّثة (`consolidated=True`)
- `python3 prepare_src.py <مجلد القوانين>` يضع الملفات في `src/consolidated/<md5>.pdf` بالأسماء المسجلة في `registry.py`.
- رؤوس المواد بصيغ المجمِّع: `(المادة 107:)`، `(المادة 2 إصدار:)`، `مادة رقم (1) — المادة …`، والرقم الجانبي `side_numbers`.
- تُجرّب طريقتا الاستخراج وتُختار الأفضل (أكثر مواد وأقل فجوات)؛ ترقيم يبدأ من 1 مرة ثانية = اللائحة التنفيذية (`r` قبل المفتاح).
- عند وجود نص مجمّع لقانون موجود يأخذ المعرّف الأصلي، والنسخة القديمة تبقى مسودة باسم `<id>-orig`.
- `python3 finalize.py` يعيد بناء `index.json` و`REVIEW.md` ويحوّل لمسودة أي قانون ترقيمه غير مكتمل (>25% فجوات).
